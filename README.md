# ABBYY-OCR

Windows demo that sends an image to ABBYY Cloud OCR (`cloud-westus.ocrsdk.com`) and writes recognized text. Application ID and password stay as placeholders in source.

## Unit tests

`Tests/AbbyyOcrTests` checks console color constants in `utils.h` (`LOG_COLOR_GREEN`, `LOG_COLOR_YELLOW`, `LOG_COLOR_WHITE`). Build Release | x64 in Visual Studio.
